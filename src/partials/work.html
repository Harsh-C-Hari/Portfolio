01 / Featured

Personal Cloud Gaming
Orchestrator

A self-hosted cloud gaming stack: a Python agent on the host talks to a FastAPI control plane, React on the front, JWT-secured WebSockets for live telemetry, and Sunshine + Tailscale for low-latency streaming. The reason I built it: I wanted to play my desktop library from my laptop over a flaky network and learn every layer of a real distributed system in the process.

What it does
Provisions game sessions, streams input/output, monitors host health, and authenticates clients — all from a single dashboard.
What I learned
Auth flows that don't lie, WebSocket lifecycle, why "low latency" is a system property, not a feature.
React FastAPI Python WebSockets JWT Sunshine Tailscale

02 / Platform

Future of CEC

A campus platform for the College of Engineering Chengannur community. Google auth, role-based access for students and lift operators, an integrated AI assistant (local Gemma via Ollama) for student queries, and workflows that actually map to the way the campus runs — including a deliberately simple lift-access request flow that doesn't require an IT ticket.

What it does
Single place for student queries, lift access, and campus information, backed by a local LLM for the AI assistant.
What I learned
Designing auth for a closed community, running a local LLM in production, and shipping a feature that real students depend on.

03 / Hackathon build

Smart Farming
Dashboard

Built during a hackathon: a dashboard that ingests soil and weather sensor data, surfaces trends with Chart.js, and uses an AI agronomy layer to suggest next actions. FastAPI serves the API; the front end focuses on a single screen that a farmer can read in under five seconds.

What it does
Real-time sensor visualization, AI-driven recommendations, decision-grade summaries at a glance.
What I learned
Designing for non-technical users, batching async sensor writes, and how much a clear chart matters more than a clever model.
